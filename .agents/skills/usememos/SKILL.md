# Memos (usememos)

Manage memos on a self-hosted Memos instance (`https://www.usememos.com`) via MCP. Single-user account (admin). AI and human memos are differentiated by tags, not by separate accounts.

> **Generic skill** — replace `{{MEMOS_URL}}`, `{{MEMOS_PAT}}`, and `{{MEMOS_USER}}` with your instance values. See [Setup](#setup).

## Setup

1. **Create a bot-free single user** — use your admin account. Do not create a separate bot account.
2. **Generate a Personal Access Token (PAT)** in Memos: Settings → Access Tokens.
3. **Set environment variable** in your shell rc file (`~/.zshrc` / `~/.bashrc`):
   ```bash
   export MEMOS_PAT="memos_xxx_your_admin_token"
   ```
4. **Add to OpenCode config** (`~/.config/opencode/opencode.json`):
   ```json
   {
     "mcp": {
       "servers": {
         "memos": {
           "type": "remote",
           "url": "{{MEMOS_URL}}/mcp",
           "headers": {
             "Authorization": "Bearer {env:MEMOS_PAT}"
           },
           "enabled": true
         }
       }
     }
   }
   ```
   Replace `{{MEMOS_URL}}` with your instance URL (e.g., `https://memos.example.com`).
5. **Restart OpenCode** fully. Verify with `opencode mcp list` — memos should show `connected`.

## Convention: AI vs Human Memos

| Source | Tag | Visibility |
|--------|-----|------------|
| AI-generated | `#ai-generated` | `PROTECTED` (visible to all logged-in users) |
| Human-created | *(none)* | Any (user's choice) |

**Rule:** Every memo created by AI MUST include `#ai-generated` tag in content. Human memos never have this tag.

## Memo Format Rules

1. **Title required** — short, descriptive (1 line, max ~60 chars)
2. **Context required** — relevant background depending on topic (project, branch, issue, etc.)
3. **Concise** — max 20-30 lines total. Use bullet points (`-`) and tables for density
4. **Avoid long paragraphs** — break into points or tables
5. **Tags** — 2-4 tags, relevant to topic. Format `#tag` in content, not as separate field
6. **Tags above footer** — not below, not with "Tags:" prefix

## Tagging Strategy

Each memo should have **2-4 tags** total in content (as `#tag`):

1. **Source tag** (always for AI): `#ai-generated`
2. **Topic tags** (1-3): relevant to memo content — e.g., `#opencode`, `#mcp`, `#setup`, `#project-name`, `#bugfix`, `#meeting-notes`, `#todo`

**Bad:** `#ai-generated #ai-generated #misc` (redundant, vague)
**Good:** `#ai-generated #opencode #mcp #setup`

## Template

```
## [Short descriptive title]

**Context:** [Relevant background — project, branch, issue, etc.]

[Content — points, tables, or combination. Max 20-30 lines total.]

#ai-generated #topic1 #topic2

---
🤖 Generated by AI (OpenCode)
```

## Creating a Memo

Use `tools.memos.memo_create_memo` with:

```json
{
  "body": {
    "content": "## Title\n\n**Context:** ...\n\n- point 1\n- point 2\n\n#ai-generated #topic1\n\n---\n🤖 Generated by AI (OpenCode)",
    "visibility": "PROTECTED"
  }
}
```

**Default: create new.** Update existing memo only when user explicitly requests.

## Visibility Guide

| Visibility | Who can see |
|------------|-------------|
| `PRIVATE` | Only creator |
| `PROTECTED` | All logged-in users |
| `PUBLIC` | Everyone (including unauthenticated) |

**Default for AI memos:** `PROTECTED` (so admin can see them).

## Listing Memos

```json
// All memos
tools.memos.memo_list_memos({})

// Filter by tag
tools.memos.memo_list_memos({ body: { filter: "tag in ['ai-generated']" } })

// Filter by visibility
tools.memos.memo_list_memos({ body: { filter: "visibility == 'PROTECTED'" } })

// Paginate
tools.memos.memo_list_memos({ body: { pageSize: 20, pageToken: "..." } })
```

## Searching Memos

```json
tools.memos.memo_search_memos({ body: { query: "search term" } })
```

## Getting a Single Memo

```json
tools.memos.memo_get_memo({ name: "memos/<memo-id>" })
```

## Updating a Memo

```json
{
  "memo": "memos/<memo-id>",
  "body": {
    "content": "Updated content\n\n#ai-generated #topic1\n\n---\n🤖 Generated by AI (OpenCode)",
    "visibility": "PROTECTED"
  }
}
```

## Deleting a Memo

```json
tools.memos.memo_delete_memo({ name: "memos/<memo-id>" })
```

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| AI memo without `#ai-generated` tag | Always include it in content |
| Using "Tags:" prefix before tags | Just use raw `#tag` in content |
| Tags below the footer | Tags go above `🤖 Generated by AI` |
| Memo without title | Title required, short & descriptive |
| Memo without context | Context required, relevant to topic |
| Memo too long (>30 lines) | Condense, use points & tables |
| Long paragraphs | Break into points or tables |
| Using `PRIVATE` for AI memos | Use `PROTECTED` so admin can see |
| Forgetting topic tags | Add 1-3 relevant topic tags |
| Vague tags like `#misc` or `#note` | Use specific, searchable tags |
| Creating memo with bot account | Use single user (admin) account |

|--------|------|------------|
| Create | `memo_create_memo` | `body.content`, `body.visibility` |
| List | `memo_list_memos` | `body.filter`, `body.pageSize`, `body.pageToken` |

| Get | `memo_get_memo` | `name` |
| Update | `memo_update_memo` | `memo`, `body` |
| Delete | `memo_delete_memo` | `name` |

## Configuration

- **MCP type**: `remote` (HTTP-based)
- **URL**: `{{MEMOS_URL}}/mcp` (replace with your instance URL)
- **Auth**: `Bearer {env:MEMOS_PAT}`
- **Account**: Single user (admin) — no separate bot account
- **Env var**: `MEMOS_PAT` in shell rc file
- **Config file**: `~/.config/opencode/opencode.json`
