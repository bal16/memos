# Memos (usememos) — Bahasa Indonesia

Kelola memo di instance Memos self-hosted (`https://www.usememos.com`) via MCP. Akun single user (admin). Memo AI dan manusia dibedakan via tag, bukan akun terpisah.

> **Skill generik** — ganti `{{MEMOS_URL}}`, `{{MEMOS_PAT}}`, dan `{{MEMOS_USER}}` dengan nilai instance kamu. Lihat [Setup](#setup).

## Setup

1. **Pakai akun admin** — jangan buat akun bot terpisah.
2. **Generate Personal Access Token (PAT)** di Memos: Settings → Access Tokens.
3. **Set env var** di shell rc file (`~/.zshrc` / `~/.bashrc`):
   ```bash
   export MEMOS_PAT="memos_xxx_token_admin_kamu"
   ```
4. **Tambah ke config OpenCode** (`~/.config/opencode/opencode.json`):
   ```json
   {
     "mcp": {
       "servers": {
         "memos": {
           "type": "remote",
           "url": "{{MEMOS_URL}}/mcp",
           "headers": {
             "Authorization": "Bearer {env:MEMOS_PAT}"
           },
           "enabled": true
         }
       }
     }
   }
   ```
   Ganti `{{MEMOS_URL}}` dengan URL instance kamu (misal `https://memos.example.com`).
5. **Restart OpenCode** penuh. Verifikasi dengan `opencode mcp list` — memos harus `connected`.

## Konvensi: Memo AI vs Manusia

| Sumber | Tag | Visibility |
|--------|-----|------------|
| Buatan AI | `#ai-generated` | `PROTECTED` (terlihat semua user login) |
| Buatan manusia | *(tidak ada)* | Bebas (pilihan user) |

**Aturan:** Setiap memo buatan AI WAJIB menyertakan tag `#ai-generated` di content. Memo manusia tidak pernah punya tag ini.

## Aturan Format Memo

1. **Judul wajib** — singkat, deskriptif (1 baris, max ~60 karakter)
2. **Konteks wajib** — latar belakang relevan tergantung topik (project, branch, issue, dll)
3. **Singkat** — maks 20-30 baris total. Gunakan point (`-`) dan tabel
4. **Hindari paragraf panjang** — pecah jadi point atau tabel
5. **Tags** — 2-4 tags, relevan dengan topik. Format `#tag` di content, bukan field terpisah
6. **Tags di atas footer** — bukan di bawah, bukan dengan prefix "Tags:"

## Strategi Tagging

Setiap memo punya **2-4 tags** total di content (sebagai `#tag`):

1. **Source tag** (selalu untuk AI): `#ai-generated`
2. **Topic tags** (1-3): relevan dengan isi memo — misal `#opencode`, `#mcp`, `#setup`, `#project-name`, `#bugfix`, `#meeting-notes`, `#todo`

**Buruk:** `#ai-generated #ai-generated #misc` (redundant, vague)
**Baik:** `#ai-generated #opencode #mcp #setup`

## Template

```
## [Judul singkat & deskriptif]

**Konteks:** [Latar belakang relevan — project, branch, issue, dll]

[Isi — point, tabel, atau kombinasi. Maks 20-30 baris total.]

#ai-generated #topic1 #topic2

---
🤖 Generated by AI (OpenCode)
```

### Contoh

```
## MCP Memos Setup Complete

**Konteks:** OpenCode di laptop, instance Memos di Vercel + Neon.
```

## Membuat Memo

Gunakan `tools.memos.memo_create_memo` dengan:

```json
{
  "body": {
    "content": "## Judul\n\n**Konteks:** ...\n\n- point 1\n- point 2\n\n#ai-generated #topic1\n\n---\n🤖 Generated by AI (OpenCode)",
    "visibility": "PROTECTED"
  }
}
```

**Default: buat baru.** Update memo lama hanya kalau user secara eksplisit minta.

## Panduan Visibility

| Visibility | Siapa bisa lihat |
|------------|------------------|
| `PRIVATE` | Hanya creator |
| `PROTECTED` | Semua user yang login |
| `PUBLIC` | Semua orang (termasuk tanpa login) |

**Default untuk memo AI:** `PROTECTED` (supaya admin bisa lihat).

## List Memo

```json
// Semua memo
tools.memos.memo_list_memos({})

// Filter by tag
tools.memos.memo_list_memos({ body: { filter: "tag in ['ai-generated']" } })

// Filter by visibility
tools.memos.memo_list_memos({ body: { filter: "visibility == 'PROTECTED'" } })

// Paginate
tools.memos.memo_list_memos({ body: { pageSize: 20, pageToken: "..." } })
```

## Search Memo

```json
tools.memos.memo_search_memos({ body: { query: "kata kunci" } })
```

## Get Satu Memo

```json
tools.memos.memo_get_memo({ name: "memos/<memo-id>" })
```

## Update Memo

```json
{
  "memo": "memos/<memo-id>",
  "body": {
    "content": "Konten baru\n\n#ai-generated #topic1\n\n---\n🤖 Generated by AI (OpenCode)",
    "visibility": "PROTECTED"
  }
}
```

## Delete Memo

```json
tools.memos.memo_delete_memo({ name: "memos/<memo-id>" })
```

## Kesalahan Umum

| Kesalahan | Perbaikan |
|-----------|-----------|
| Memo AI tanpa tag `#ai-generated` | Selalu sertakan di content |
| Pakai prefix "Tags:" sebelum tags | Langsung pakai `#tag` di content |
| Tags di bawah footer | Tags di atas `🤖 Generated by AI` |
| Memo tanpa judul | Judul wajib, singkat & deskriptif |
| Memo tanpa konteks | Konteks wajib, relevan dengan topik |
| Memo terlalu panjang (>30 baris) | Ringkas, gunakan point & tabel |
| Paragraf panjang | Pecah jadi point atau tabel |
| Pakai `PRIVATE` untuk memo AI | Pakai `PROTECTED` supaya admin bisa lihat |
| Lupa topic tags | Tambah 1-3 topic tags relevan |
| Tag vague seperti `#misc` atau `#note` | Pakai tag spesifik dan searchable |
| Buat memo dengan akun bot | Pakai single user (admin) |

## Konfigurasi

- **MCP type**: `remote` (HTTP-based)
- **URL**: `{{MEMOS_URL}}/mcp` (ganti dengan URL instance kamu)
- **Auth**: `Bearer {env:MEMOS_PAT}`
- **Akun**: Single user (admin) — tidak pakai akun bot terpisah
- **Env var**: `MEMOS_PAT` di shell rc file
- **Config file**: `~/.config/opencode/opencode.json`
